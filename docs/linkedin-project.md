# LinkedIn Project Entry

## Title

Oracle ETL Batch Framework

## Description

Designed and implemented a reusable Oracle PL/SQL ETL batch framework for execution tracking, job orchestration, error logging, rejected-row handling and restartable data processing.

The project separates generic orchestration from business-specific load logic and demonstrates idempotent upsert processing, autonomous diagnostic logging and operational row-count metrics.

Technologies: Oracle Database, SQL, PL/SQL, ETL, MERGE, exception handling, autonomous transactions.
